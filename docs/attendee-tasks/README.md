# BrickList Attendee Tasks

You have BrickList running. Nice one. Work through these tasks in order with your pair.

| Task | What you will practise |
| --- | --- |
| [1. Make it yours](01-make-it-yours.md) | Find a screen, change it, watch hot reload |
| [2. Find some bricks](02-find-some-bricks.md) | State, inputs, and a real authenticated API request |
| [3. Befriend failure](03-befriend-failure.md) | Loading, empty, error, and retry states |
| [4. Cross the native boundary](04-cross-the-native-boundary.md) | Why Expo Go has limits; development builds and one native package |

Take a break at 1:00. Ask for a helper early if you are blocked for more than five minutes. Getting unstuck is part of the workshop, not a side quest.

## Rules of the road

- Follow the tasks one by one, use agentic development to progress through the tasks.
- If you get stuck with your setup, ask `Frankie`
- Never paste the workshop API key into chat, a prompt, a screenshot, or Git.
- The app is for physical iOS and Android phones through Expo Go. Do not start native builds until Task 4.
