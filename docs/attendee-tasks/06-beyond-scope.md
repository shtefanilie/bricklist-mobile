# Task 6: Have Fun

## Mission

Congratulations! You've finished the main path. If you want to keep exploring, pick an idea below and see how far you can take BrickList. These are optional experiments, not requirements for finishing the workshop.

## Ideas to try

- Browse the [Expo demos](https://expo.dev/demos) for inspiration. Try adding an animation or a new interaction to a set card.
- Add a light and dark theme, and check that every screen remains readable in both.
- Make the set list easier to use: add sorting by year or piece count, or filter by theme.
- Take favourites further: add a dedicated favourites screen and an empty state for when nothing has been saved yet.
- Let people share a set from its details screen using the device's share sheet.
- Improve accessibility: add meaningful labels to buttons, test larger text sizes, and check how the app works with a screen reader.
- Write a test for one important interaction, such as opening a set or adding it to favourites.

Want to explore another platform? Look into [React Native TV](https://github.com/react-native-tvos/react-native-tvos#readme), [React Native macOS](https://github.com/microsoft/react-native-macos), or [React Native Windows](https://microsoft.github.io/react-native-windows/). Each has its own setup and platform-specific considerations; existing mobile screens won't automatically be ready for a TV remote or desktop input.

Check the setup and compatibility notes for any new package before installing it. Some experiments may need a development build rather than Expo Go.
