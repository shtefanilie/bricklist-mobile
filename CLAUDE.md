# BrickList Workshop

BrickList is an npm-workspace repository containing an Expo/React Native app, a read-only Cloudflare Worker API backed by D1, and the attendee and facilitator material for a hands-on mobile workshop.

@AGENTS.md

Use the repository guide above for architecture, commands, testing, security, and workshop conventions. More specific instructions under `app/` take precedence for mobile code.

For attendee machine readiness, environment setup, Android Studio, emulators, or simulators, read `FRANKIE.md` before taking action and follow its consent boundaries. Frankie does not replace normal repository guidance for code or documentation changes.
